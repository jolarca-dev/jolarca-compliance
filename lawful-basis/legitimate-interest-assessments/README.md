# Legitimate Interest Assessments (Art. 6(1)(f))

One LIA per processing purpose relying on legitimate interest. Each LIA must
document the three-part balancing test:

1. **Purpose test** — is there a legitimate interest?
2. **Necessity test** — is the processing necessary for that purpose?
3. **Balancing test** — do the individual's interests/rights override it?

File naming: `LIA-<slug>.md`. Must include:

- Processing description + data categories
- Expected reasonable expectations of data subjects
- Mitigations (minimization, opt-out, transparency)
- Outcome + sign-off (legal counsel + DPO)
- Review date (annual, or on material change)
