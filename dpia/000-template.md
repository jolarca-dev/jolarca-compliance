# DPIA 000 — Master template

> Copy `docs/DPIA-template.md` into a new numbered folder
> (`NNN-slug/`) and rename to `dpia.md`. Do not edit the template in place.

## Naming & versioning

- Folder: `NNN-short-slug/`, NNN = next number in `register.md`.
- File: `dpia.md` with metadata block (version, owner, reviewers, status).
- Status flow: `draft → reviewed → signed`. Signed = immutable.

## Required sections (see docs/DPIA-template.md for the full form)

1. Context & processing description (data categories, flows, volumes)
2. Necessity & proportionality (lawful basis, purpose limitation, minimization)
3. Risk assessment (likelihood × impact, before/after mitigation)
4. Measures (technical + organizational) with control references (Annex A / TSC)
5. Consultations (data subjects/representatives, processors)
6. DPO opinion + sign-off block
7. Review date & linked artifacts (RoPA IDs, risk-register IDs, gate)
