# Breach Notification — Data Subjects (Art. 34)

Required only where the breach is likely to result in a **high risk** to
rights and freedoms. Decision must be documented in the incident folder.

- Clear, plain language; per-language versions below
- Content: nature of breach, DPO contact, likely consequences, measures,
  recommendations for the individual
- Channels: email + in-app notice; website banner if widespread

Languages (one file each, reviewed by legal):

- [ ] lt/ — Lithuanian
- [ ] lv/ — Latvian
- [ ] et/ — Estonian
- [ ] en/ — English

Distribution evidence (counts, channel, timestamp) is archived with the
incident folder and hashed.
