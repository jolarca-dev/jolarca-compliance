# Postmortem Template

Blameless. Focus on system causes, not individuals. Mandatory for
Critical/High; actions tracked to closure.

- Incident ID / severity / detection → resolution timeline (UTC)
- Impact: users, data categories, financial, regulatory
- Root cause analysis (5-whys or equivalent)
- What worked / what didn't (detection, comms, tooling)
- **Action items**: owner, due date, linked risk-register ID where systemic
- Lessons → policy change proposals (link PRs)
- Evidence list + hashes

Sign-off: incident commander + DPO (if personal data involved).
