# Security Training & Awareness Program

## Structure

| Track | Audience | Frequency |
|---|---|---|
| Onboarding: GDPR basics + security fundamentals + this repo's rules | All new hires | Before production access |
| Annual awareness refresh | Everyone | Yearly |
| Secure development | Engineers | Yearly + on policy change |
| DSR handling | Support | Yearly + on template change |
| Retention & financial records | Finance | Yearly |
| Phishing simulation | Everyone | Semi-annual |

## Rules

- Completion is recorded in `completion-log.md` (SOC 2 CC1.4 evidence);
  access to production is gated on onboarding completion.
- Materials in `materials/` are versioned; role-specific decks reference the
  policy versions they teach.
- Failed phishing simulations → repeat training within 14 days; reporting is
  aggregated, never punitive.
